# Leaf — Social Token Launchpad UI

A responsive, single-page prototype inspired by the supplied Leaf screenshot.

## Included
- Dark green premium UI
- Responsive desktop/tablet/mobile layout
- Sticky navigation
- Hero + market ticker
- Multi-step token launch builder
- X creator identity step
- Token name/symbol/pair selection
- Fee allocation sliders with 100% validation
- Review + simulated on-chain lock
- Demo launch success state
- Explore launches with filters
- Creator dashboard cards
- Wallet connection modal (simulated)
- Light/dark theme toggle
- Animated-style chart drawn with Canvas
- No backend and no real crypto transactions

## Run
Open `index.html` directly in a browser, or serve the folder with any static server.

For example:
`python -m http.server 8000`

Then visit `http://localhost:8000`.

## Production next steps
Connect the UI to your preferred backend, X OAuth, wallet provider, smart contracts, indexing, database, and authentication. Do not treat the demo transaction flow as production-safe.
